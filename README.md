# TrustGuard

## Protecting Users from Online Scams

### Problem Statement
Online scams use fraudulent messages, impersonation, and suspicious links to trick people into sharing personal information or losing money. Many users find it difficult to recognize warning signs before becoming victims.

### Our Solution
TrustGuard is a browser-based security project designed to help users identify potentially suspicious messages. It analyzes submitted text using predefined JavaScript rules and provides warning indicators to support safer online decisions.

### Features
- Suspicious message analysis
- Detection of predefined scam warning signs
- Results presented to the user
- Safety awareness through analysis feedback
- Browser-based interface

### How It Works
1. Open the TrustGuard application.
2. Enter the message you want to check.
3. Run the analysis.
4. Review the warning indicators and results.
5. Verify suspicious messages independently before taking action.

### Technology Stack
- HTML, CSS, and JavaScript, depending on the implemented files
- Rule-based text analysis
- Browser-based application

### How to Run
Open the deployed TrustGuard application in a web browser:

https://trustguard-security-3ttv.bolt.host

### Limitations
TrustGuard uses predefined rules and cannot guarantee that every scam will be detected. A flagged message is not necessarily fraudulent, and an unflagged message is not necessarily safe.

### Project Goal
Our goal is to improve scam awareness and help users pause, recognize warning signs, and verify suspicious communications before responding.
